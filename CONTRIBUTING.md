# Contributing

Thank you for your interest in Quantarium.

**Ideas are welcome; code is not merged as it is.** Open an issue to report a bug, ask a question, or propose an idea: what you were trying to do, what happened, and what you expected. Pull requests are read as descriptions of an idea, too. When an idea fits, the maintainers write it into Quantarium in their own way, with tests, rather than merging the pull request.

This keeps the project's licensing simple. Quantarium is licensed under the [PolyForm Noncommercial License 1.0.0](LICENSE.md), and its copyright holders keep the right to license it commercially. Accepting outside code would need a contributor agreement first, which the project does not have yet.

## Before you report

- For security problems, follow [SECURITY.md](SECURITY.md) instead of opening an issue.
- Never paste API keys, tokens, account numbers, or your holdings into an issue.
- Market data you bought or downloaded may not be redistributable; describe it rather than attaching it.

## What helps most

- A short scenario, config, or data folder that shows the problem, using invented prices (`quantarium scenario generate`) where you can.
- The Quantarium version (`quantarium --version` or the app's Workspace page), your operating system, and your Python version.
